# Diseños de referencia

En esta carpeta se pueden guardar exportaciones de Figma utilizadas como referencia: imágenes de pantallas, íconos y otros recursos permitidos. Los archivos que utilice la aplicación se incorporarán en `static/img/` cuando corresponda.

Mantener los diseños originales disponibles para consultar dimensiones, colores, tipografías y estados de cada pantalla. Usar solo información ficticia o anonimizada en las imágenes.
